# tg-posts — посты в Telegram

Плагин [Agents Hub](https://github.com/flagman/agents-hub-core): сессия шлёт владельцу посты в Telegram по одному —
картинка с подписью, — а он отвечает на каждый отдельно.

- **Варианты постов.** Из файла черновиков (`## N. Название`) — сообщение на пост. Реплай голосом или текстом приходит
  той сессии, что прислала, с пометкой поста и путём к картинке.
- **Колода.** Карточки с кнопками ❤️ 👎. Нажатие и реплай словами плагин сам отдаёт серверу колоды (`/api/decide`,
  `/api/direct`) — без хода сессии. Адрес — в `hub.json`: `"extensions": {"<имя плагина>": {…, "deck": "http://localhost:7777"}}`.

Нужен хаб с фактом `telegram.post` (модуль Telegram отправляет пост, нажатие — `telegram.pressed`, реплай —
`telegram.replied`).

Сессии — скилл `tg-posts` (как отправить, что придёт в ответ).

Иконка — [3D Fluency](https://icons8.com/icons/3d-fluency) от Icons8.
