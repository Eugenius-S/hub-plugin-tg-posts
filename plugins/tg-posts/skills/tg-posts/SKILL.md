# Посты в Telegram

Каждый пост — отдельное сообщение: картинка, подпись под ней. Владелец отвечает реплаем на конкретный пост — голосом
или текстом, — и его слова приходят тебе сообщением с пометкой `(в ответ на пост <файл> #N Название, файл <путь>)`.

## Варианты постов из файла черновиков

Посты в файле — разделы `## N. Название`; в Telegram уходит «N. Название» и тело раздела. Картинку к посту называешь сам:

```
python3 "${CLAUDE_PLUGIN_ROOT}/bin/tg-posts" drafts <полный путь к drafts.md> \
  --image 3=<полный путь к картинке> --image 5=<…> [--only 3,5,7]
```

- `--image N=<путь>` — картинка поста N (png, jpg, webp до 10 МБ); без неё пост уходит текстом.
- `--only` — только эти номера; без него — все разделы файла.
- Текст длиннее 1000 знаков — картинка, следом текст отдельным сообщением; реплай на любое из двух — к тому же посту.

Пришёл реплай — отметь отзыв у поста N в файле черновиков и доработай пост; ответ владельцу — коротко.

## Колода с кнопками ❤️ 👎

```
python3 "${CLAUDE_PLUGIN_ROOT}/bin/tg-posts" deck [--count 10]
```

Берёт неоценённые карточки сервера колоды (`GET <колода>/api/deck`; адрес — `deck` у плагина в hub.json, по умолчанию
`http://localhost:7777`) и шлёт каждую с кнопками. Нажатие ❤️ / 👎 и реплай словами плагин сам отдаёт колоде
(`/api/decide`, `/api/direct`) — тебе ничего делать не надо, хода на это не тратится.
